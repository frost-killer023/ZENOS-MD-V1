# ⚡ ZENOS-MD-V1 ⚡

Un bot WhatsApp moderne, ultra-rapide et ultra-stable, conçu en Node.js 20+ avec `@whiskeysockets/baileys`. 

## 🚀 Caractéristiques principaux
- 🔒 **Mode Privé Strict :** Seul le numéro configuré dans le fichier `.env` peut exécuter les commandes.
- 🛡️ **Anti-Crash Intégré :** Pas d'arrêts imprévus grâce à la capture globale des rejections et exceptions de processus.
- ⚡ **Prêt pour le déploiement Cloud :** Intègre un mini-serveur Express requis pour garder les applications en vie sur Render, Railway ou Replit.

## 🛠️ Installation Locale

1. Clonez ce dépôt.
2. Créez votre fichier `.env` basé sur `.env.example` et remplissez vos identifiants.
3. Installez les paquets requis :
   ```bash
   npm install
   ```
4. Lancez le projet :
   ```bash
   npm start
   ```
5. Scannez le QR code affiché sur votre terminal avec WhatsApp.
